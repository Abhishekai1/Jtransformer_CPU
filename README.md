# JTransformer

A Java-based CPU-optimized mini Transformer framework for research.

## Features
- Java 21 + Virtual Threads
- ND4J for tensor operations
- Quantization (Int8, Binary)
- Sparse Attention
- Tiny Transformer Training

## Quick Start
```bash
mvn clean compile
mvn exec:java
```

See `docs/architecture.md` for details.
